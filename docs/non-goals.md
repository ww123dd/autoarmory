# Non-goals

AutoArmory does not:
- become a generic Agent manager;

- replace SkillCanary;
- run agents;
- become a security scanner;
- become a registry;
- automatically execute changes without human approval;
- train on raw private transcripts;
- claim self-evolution from synthetic data alone.

- become a generic agent evaluator or implement domain simulators. Scenario profiles are routing/evidence contracts; domain execution comes from adapters.
